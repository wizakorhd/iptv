How to watch

Load the playlist URL in any IPTV player, then add the EPG (guide) URL for a programme schedule. All players below are free and open-source or have a free tier.

VLC
Open Network Stream → paste the playlist URL. Simplest way to test on any OS.
Windows · macOS · Linux · Android · iOS
Jellyfin
Live TV → add an M3U Tuner (playlist URL) and an XMLTV guide (EPG URL). Best for a home server.
Self-hosted · all clients
Kodi
Add the “PVR IPTV Simple Client” add-on, then point it at the playlist + EPG URLs.
Windows · macOS · Linux · Android
IPTVnator
Open-source desktop IPTV player — add a playlist by URL and it picks up EPG automatically.
Windows · macOS · Linux
TiviMate / OTT Navigator
Popular Android-TV players (free tiers). Add a playlist by URL, then the EPG URL.
Android · Android TV · Fire TV
mpv / termv
For the terminal: pipe a channel URL to mpv, or browse the M3U with termv.
Windows · macOS · Linux
  1. Copy the playlist URL (or the faster jsDelivr CDN URL) from the buttons above.
  2. In your player, add a playlist / M3U source and paste that URL.
  3. Copy the EPG URL and add it as the XMLTV / guide source for programme names & times.
